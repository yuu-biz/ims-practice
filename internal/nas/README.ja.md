# SMS を運ぶ NAS のメッセージ

[English](README.md)

このパッケージは、UE とコア網のあいだで SMS を運ぶ NAS のメッセージを読み書きします。SMS の CP 層（TS 24.011）、EPS の UPLINK NAS TRANSPORT と DOWNLINK NAS TRANSPORT（TS 24.301）、5GS の UL NAS TRANSPORT と DL NAS TRANSPORT（TS 24.501）です。

このプロジェクトのノードは、どれもこのパッケージを使っていません。試験は、メッセージごとにオクテットの並びと照らします。

```sh
go test ./internal/nas
go doc ./internal/nas
```

## このパッケージで簡略化していること

どの行の場所にも、コードに `SIMPLIFIED:` のコメントがあります。

| 場所 | 省いたこと | 理由 |
| --- | --- | --- |
| `marshal5GMMNASTransport`、TS 24.501 8.2.10、8.2.11 | SMS のほかのペイロードコンテナの種類と、その種類に要る任意の要素（PDU セッション ID など）。ほかの種類のメッセージは断ります。 | ほかの種類は、5GS のセッション管理など、別の手順のメッセージを運びます。このパッケージが扱うのは、NAS の上の SMS だけです。 |
| `marshal5GMMNASTransport`、TS 24.501 4.4.4.1、4.4.5 | 完全性の保護と暗号化。保護したメッセージは、平文のメッセージの前にメッセージ認証コードと順序番号を置きます。読み書きするのは平文のメッセージだけです。 | 鍵は 5G AKA とセキュリティモードの制御の手順から来ます。どちらもこのパッケージにはありません。 |
| `parse5GMMNASTransport`、TS 24.501 8.2.10、8.2.11、7.6.1 | ペイロードコンテナのあとの任意の要素を読むこと。無視します。「comprehension required」と符号化された知らない要素も無視します。 | 種類が SMS のペイロードには、これらの要素が付きません。 |
| `marshalEMMNASTransport`、TS 24.301 4.4.2.3、4.4.4.1、4.4.5 | 完全性の保護と暗号化。保護したメッセージは、平文のメッセージの前にメッセージ認証コードと順序番号を置きます。読み書きするのは平文のメッセージだけです。 | 鍵は EPS AKA とセキュリティモードの制御の手順から来ます。どちらもこのパッケージにはありません。 |
| `parseEMMNASTransport`、TS 24.301 7.6.1、TS 24.007 11.2.5 | NAS メッセージコンテナのあとのオクテットを、情報要素として読むこと。無視します。受け手が断るべき「comprehension required」の要素も無視します。 | どちらのメッセージにも任意の要素がありません。 |
| `ParseCP`、TS 24.007 11.2.4、11.2.5 | CP メッセージの最後の要素のあとのオクテットを、情報要素として読むこと。無視するので、壊れた要素があっても気づきません。 | TS 24.011 は、どの CP メッセージにも任意の要素を定めていません。 |
