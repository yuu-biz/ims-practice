# EVS のペイロード

[English](README.md)

このパッケージは、EVS の音声のフレームを、TS 26.445 Annex A の形式で RTP とファイルに入れて運びます。RTP のペイロードの Compact と Header-Full（A.2.1、A.2.2）と、ファイルに保存する形式（A.2.6）です。パッケージ `amr` と同じく、音声を符号化も復号もしません。フレームは符号化された形でほかから届き、そのまま運ばれ、次に渡されます。パッケージ `sdp` は、EVS のセッションで決めたペイロードの形式と、フレームの種類ごとの大きさを、このパッケージから得ます。

```sh
go test ./internal/evs
go doc ./internal/evs
```

## このパッケージで簡略化していること

どの行の場所にも、コードに `SIMPLIFIED:` のコメントがあります。

| 場所 | 省いたこと | 理由 |
| --- | --- | --- |
| パッケージ `evs`、TS 26.445 A.2.5 | モノラルのチャネルが 2 つ以上あるセッション（デュアルモノ）。どのパケットも、1 つのチャネルのフレームを運びます。 | IR.92 も NG.114 も求めていません。TS 26.114 5.2.1.4 は、デュアルモノを任意としています。 |
| `WriteStorage`、TS 26.445 A.2.6.1 | 2 つ以上のチャネルのファイル。チャネルの数は、いつも 1 です。 | 上の行のとおり、このパッケージが読むペイロードは 1 つのチャネルを運びます。 |
