# サービスベースのインタフェース

[English](README.md)

このパッケージは、5GC のサービスベースのインタフェースのうち、ここにあるどの API にも共通の部分です。HTTP/2（TS 29.500 5.1 から 5.4）、JSON の本文、ProblemDetails（TS 29.571 5.2.4.1）を使うエラーの応答と、TS 29.500 Table 5.2.7.2-1 のアプリケーションのエラーです。パッケージ `n5`（TS 29.514）とパッケージ `nhss`（TS 29.562）が、この上に作られています。このプロジェクトのノードは、このパッケージを動かしていません。`cmd` のどのバイナリにも組み込まれていません。動く様子は試験で見られます。

```sh
go test ./internal/sbi
go doc ./internal/sbi
```

## このパッケージで簡略化していること

どの行の場所にも、コードに `SIMPLIFIED:` のコメントがあります。

| 場所 | 省いたこと | 理由 |
| --- | --- | --- |
| パッケージ `sbi`、TS 29.500 5.1 | TLS、OAuth 2.0 のアクセストークン、NRF。SBI は平文の HTTP/2（事前の知識による h2c、RFC 9113 3.3）で動き、呼ぶ側には相手の apiRoot を渡します。 | このプロジェクトのほかの部分と同じく、キャプチャでメッセージを読めるように平文にしています。TS 29.500 5.1 は、ほかの手段で守られた網では TLS を使わなくてよいとしています。TS 29.514 と TS 29.562 の OpenAPI のファイルのセキュリティの節も、トークンの無い要求を認めています。 |
| `NewHTTPClient`、TS 29.500 6.10.9 | 307 と 308 による、サービスのほかのインスタンスへの転送には従いません。エラーとして返します。 | NRF も、転送先になる 2 つ目のインスタンスもありません。呼ぶ側には、話す相手を 1 つだけ渡します。 |
| `ProblemDetails`、TS 29.571 5.2.4.1 | アクセストークン、NRF、API の版についての属性。 | ここでは、NRF も OAuth 2.0 も使いません。 |
